# Installation: 
download and run the installer. If the installation does not complete on the first attempt, simply restart the installer (2–4 attempts usually solve the problem).

# First launch: 
open the app, select a theme and language.

# Adding habits: 
click “Add habit,” set a name, category, and parameters.

# Daily check-in: 
mark completed days in the calendar or list.
# Analytics: 
view progress, streaks, and statistics on the main screen.
# Reminders: 
enable notifications for the habits you want.
# Subscriptions: 
you can sign up/activate a subscription via the Telegram bot @trackersubscribebot.

# Export/import: save data or transfer it between devices.
